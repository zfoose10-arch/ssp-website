# ssp-website

The Summit Spring Partners public site: static HTML, CSS, fonts and scripts, with one PHP counter, count.php, and the address range list it reads, cidrs.php, published by scripts/deploy.sh over rsync after a dry run and a typed yes.

- A deploy is outbound and waits for Zane: he runs scripts/deploy.sh, which shows its dry run and publishes only on his typed yes.
- Copy follows the vault's writing conventions: no em dashes, and no hyphen used as punctuation to join clauses.
